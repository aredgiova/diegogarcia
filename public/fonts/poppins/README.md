# Poppins

Official Google Fonts Poppins assets, downloaded on 2026-10-14.

- Style: normal.
- Weights: 400, 500, 600, 700, 800.
- Format and subset: WOFF2, Latin (including Spanish accents).
- CSS source: https://fonts.googleapis.com/css2?family=Poppins:wght@400;500;600;700;800&display=swap
- Binary source: https://fonts.gstatic.com/s/poppins/v24/
- License: SIL Open Font License 1.1, included unchanged in `OFL.txt`.
- License source: https://raw.githubusercontent.com/google/fonts/main/ofl/poppins/OFL.txt

Files are named `poppins-latin-{weight}-normal.woff2` for local hosting.
