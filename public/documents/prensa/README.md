# Boletines y comunicados de prensa

Los documentos se sirven directamente como PDF, sin modificar su contenido.

Para añadir un boletín:

1. Copiar el PDF a esta carpeta con un nombre estable y descriptivo.
2. Añadir su registro a `src/config/press.ts`, colocando los más recientes primero.
3. Completar el título, la fecha, el nombre del archivo, el número de páginas y su tamaño en bytes.

La sección de prensa genera automáticamente las acciones «Ver PDF» y «Descargar» para cada registro.

El primer archivo corresponde al documento original «CP 0013DG - Comision Especial - 26 08 26.pdf» suministrado por el usuario. La fecha visible procede del nombre del archivo original.
